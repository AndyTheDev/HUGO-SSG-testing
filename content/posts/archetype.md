# Shortcodes
- Předdefinované “kousky” HTML, které mohu přidávat na stránku
- Dovolují přidávat komplexnější odkazy, tlačítka a externí funkce
- Jsou předvytvořené, ale mohu si je vytvořit sám
### Syntaxe:
```
    
```
- Např. Integrace youtube videa:
```
    {{< youtube xvFZjo5PgG0 >}}
```
- Např. Varování
```
    {{< alert >}}
    **Warning!** Bouchne to!
    {{< /alert >}}
```
